Analisis Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript, dan bahasa sisi server seperti PHP atau Python | C#, Java, C++, Python, dan JavaScript | Kotlin, Java, Swift, Dart, dan JavaScript |
| Arsitektur | Umumnya menggunakan arsitektur client-server. Browser mengirim permintaan ke server melalui jaringan. | Aplikasi berjalan pada sistem operasi komputer dan dapat memproses data secara lokal atau terhubung ke server. | Aplikasi berjalan pada sistem operasi perangkat mobile, seperti Android atau iOS, dan dapat menggunakan layanan lokal maupun server. |
| Cara distribusi | Diakses melalui browser menggunakan URL tanpa harus memasang aplikasi utama di perangkat. | Umumnya didistribusikan melalui installer, toko aplikasi, atau paket aplikasi. | Umumnya didistribusikan melalui Google Play Store, Apple App Store, atau file instalasi yang sesuai. |
| Keunggulan | Mudah diakses dari berbagai perangkat, pembaruan dapat dilakukan di server, dan tidak selalu memerlukan instalasi. | Dapat memanfaatkan sumber daya komputer secara langsung, mendukung pekerjaan kompleks, dan dapat berjalan secara offline jika dirancang demikian. | Praktis dibawa, mendukung layar sentuh, dan dapat memanfaatkan kamera, GPS, serta sensor perangkat. |
| Keterbatasan | Bergantung pada browser dan sering memerlukan koneksi internet untuk fitur berbasis server. Akses perangkat juga dibatasi oleh browser. | Perlu penyesuaian terhadap sistem operasi dan perangkat tertentu. Instalasi serta pembaruan dapat memerlukan pengelolaan tersendiri. | Perlu memperhatikan ukuran layar, baterai, kompatibilitas perangkat, serta perbedaan sistem operasi dan versi. |
| Contoh aplikasi | Gmail versi web, Google Docs versi web, dan sistem informasi akademik berbasis browser. | Microsoft Word versi desktop, Visual Studio Code, dan aplikasi kalkulator desktop. | WhatsApp versi mobile, Google Maps, dan aplikasi mobile banking. |

Refleksi

Platform yang paling menarik bagi saya untuk dipelajari adalah Web karena aplikasi web dapat diakses melalui browser tanpa harus selalu memasang aplikasi di setiap perangkat. Selain itu, pengembangan web memberikan kesempatan untuk mempelajari HTML, CSS, JavaScript, serta cara kerja komunikasi antara client dan server. Saya berharap dapat membuat website yang bermanfaat dan mudah digunakan oleh orang lain.

Tantangan terbesar yang saya hadapi saat menyiapkan lingkungan pengembangan adalah memastikan semua perangkat lunak terinstal dengan benar. Saya perlu memeriksa versi Git, Node.js, NPM, dan Java melalui CMD. Saya juga sempat mengalami kendala saat menentukan folder instalasi Android Studio karena folder yang dipilih tidak kosong. Selain itu, ketika melakukan clone repository GitHub, muncul peringatan bahwa repository masih kosong. Setelah diperiksa, hal tersebut terjadi karena belum ada file yang dimasukkan ke dalam repository.

Untuk mengatasi tantangan tersebut, saya akan mengikuti dokumentasi resmi setiap perangkat lunak, membaca pesan kesalahan dengan teliti, dan mencari solusi secara bertahap. Saya juga akan berlatih menggunakan Visual Studio Code dan GitHub agar lebih terbiasa membuat file, melakukan commit, dan mengunggah perubahan ke repository. Dengan latihan yang konsisten, saya berharap dapat mengembangkan aplikasi dengan lebih baik pada pertemuan berikutnya.
